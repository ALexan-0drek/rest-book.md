# jankenpo-elixir

Há uma gravação com o jogo rodando.

## Instalação da linguagem

O procedimento completo está na documentação oficial, que cobre tanto o gerenciador de versões quanto a instalação direta por pacote do sistema.

## Executar

```
> elixir index.exs
```

O arquivo é interpretado direto, sem passo de compilação: dá para editar e rodar de novo na hora.
